# AI Text Assistant

A simple web-based text processing application built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

Try the application here:

https://nessy04.github.io/ai-text-assistant/

## ✨ Features

- 📝 Text summarization
- 🔑 Keyword extraction
- 🔢 Word counting
- ⚡ Runs directly in the browser
- 💻 Simple and responsive interface

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📌 About the Project

AI Text Assistant is a portfolio project created to demonstrate front-end development and text-processing functionality using JavaScript.

The application processes text directly in the browser and does not require a paid API.

## 🔮 Future Improvements

- Integration with an AI API
- Multiple summary lengths
- Copy-to-clipboard functionality
- Dark mode
- Improved keyword analysis
- Support for multiple languages
